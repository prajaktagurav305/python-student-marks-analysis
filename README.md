# Python Student Marks Analysis

## About the Project
This is a beginner-friendly Python project that reads student records from a text file and performs basic statistical analysis on student marks.

## Features
- Reads student details from a text file.
- Displays student names and marks.
- Calculates total marks and average marks.
- Identifies the student with the highest marks.
- Identifies the student with the lowest marks.
- Filters students scoring above 25 marks.

## Concepts Used
- Python Functions
- File Handling (Read, Write)
- Loops
- Conditional Statements
- Dictionaries
- Basic Data Analysis

## Sample Input

```text
Prajakta,25
Pradnya,23
ANKITA,07
```

## Sample Output

```text
Student Analysis:
{
    'average': 18.33,
    'number_of_students': 3,
    'total_marks': 55,
    'highest_marks_student': 'Prajakta',
    'lowest_marks_student': 'ANKITA'
}
```

## How to Run

1. Clone this repository.
2. Make sure Python is installed.
3. Run the following command:

```bash
python main.py
```
